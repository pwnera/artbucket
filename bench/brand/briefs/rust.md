# Brief: Rust

Build the brand site for the Rust programming language, an unofficial showcase. Rust and the Rust logo are trademarks of the Rust Foundation; the logo is CC artwork held by the Foundation, and Ferris the crab (the mascot) is public domain, CC0, drawn by Karen Rustad Tölva (rustacean.net).

- Tagline: "A language empowering everyone to build reliable and efficient software."
- Voice: inclusive, earnest and precise. Rust explains the hard parts patiently, welcomes beginners as peers, and is exact about what the compiler promises. Avoid hype, exclamation marks, and calling it "blazing fast" without a number.
- Colors: Charcoal #2a3439 (text, headers, the logo's black on light grounds), Signal Yellow #ffc832 (the accent and every call to action, always with Charcoal text), Crimson #a72145, Night Purple #2e2459 and Teal #0b7261 (deep bands, with white text), Ferris Orange #f74c00 (Ferris's shell), Ferris Shade #a52b00, White #ffffff.
- Type: Alfa Slab One for headings, Fira Sans for text, Fira Mono for code (all on Google Fonts).
- Logo: the R in a gear, at https://www.rust-lang.org/static/images/rust-logo-blk.svg. Clear space of half the gear's height on every side; never recolor, rotate or add effects; minimum size 24px on screen.
- Mascot: Ferris, at https://rustacean.net/assets/rustacean-flat-happy.svg. Use freely, recolor, dress up.
- Sections the site needs: welcome, voice, Ferris, color, typography, logo (with do and don't), resources (rust-lang.org, rustacean.net, foundation.rust-lang.org/policies/logo-policy-and-media-guide).
