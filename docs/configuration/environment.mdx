The server reads its configuration from the environment (or `.env` next to it)
when it starts. A missing or malformed required value stops it with a message
naming the variable.

| Variable | Default | |
|---|---|---|
| `DATABASE_URL` | required | Postgres connection string |
| `S3_ENDPOINT` | required | Where the server reaches storage |
| `S3_PUBLIC_ENDPOINT` | `S3_ENDPOINT` | Where browsers reach storage, when that differs (Docker Compose) |
| `S3_REGION` | `us-east-1` | Storage region |
| `S3_BUCKET` | required | Bucket; created on start when missing |
| `S3_ACCESS_KEY_ID` `S3_SECRET_ACCESS_KEY` | required | Storage credentials |
| `S3_FORCE_PATH_STYLE` | `true` | `false` for AWS S3 and Tigris; `true` for most others |
| `APP_URL` | `http://localhost:3000` | The public origin: links, CORS for uploads, and where cookie-signed writes are taken from, beside organizations' verified domains |
| `INTERNAL_URL` | `APP_URL` | Where the server reaches its own API while rendering pages, when it can't reach `APP_URL` from inside (a container behind a proxy): `http://localhost:3000` |
| `BILLING_URL` | unset | Where an organization's admins manage the plan behind its limits: a "Manage plan" link in Settings, Usage, an "Upgrade" button in the header while the organization has no limits of its own, and named when a limit refuses something. See [Limits](/configuration/limits) |
| `GIT_CONNECT_URL` | unset | Where a brand gets connected to a Git repository by this server's Git integration, `{brand}` standing for its slug, left empty to bring a new brand in from a repository. New brand, a new brand's setup and the builder link there, for workspace admins. See [Sync API](/guides/brand-as-code/sync-api#connecting-from-the-app) |
| `DOMAIN_TARGET` | unset | The host name organizations' own domains should CNAME to, shown beside their TXT record: this server's, or a provider's (Cloudflare for SaaS's fallback origin). Unset: "point it at this server" |
| `PORTAL_DOMAIN` | unset | A domain whose subdomains are portals: `{address}.PORTAL_DOMAIN` serves that portal, beside `/p/{address}`. Needs a wildcard DNS record and certificate. See [Portals](/guides/portals#a-subdomain-for-every-portal) |
| `HUB_URL` | unset | Where BrandHub answers: a host of its own (`https://hub.example.com`) or a path on `APP_URL`'s (`http://localhost:3000/hub`). The path is always `/hub`. A host beside `APP_URL`'s (`hub.` and `app.example.com`) shares its sign-in: the session cookie is then set for `example.com`. Unset: no hub. See [Portals](/guides/portals#brandhub) |
| `BETTER_AUTH_SECRET` | required in production | Signs sessions, encrypts secrets in settings. `openssl rand -base64 32` |
| `SIGNUP` | `invite` | `open`: anyone may make an account, and gets an organization of their own |
| `SETUP_TOKEN` | unset | Asked for by the first account, the admin of everything, so whoever reaches a fresh server first can't make it. Unset: anyone can, and the log warns at start until someone has |
| `OIDC_ISSUER` `OIDC_CLIENT_ID` `OIDC_CLIENT_SECRET` | unset | Single sign-on; all three or none. See [Authentication](/configuration/auth) |
| `OIDC_NAME` | `SSO` | The button: "Sign in with `OIDC_NAME`" |
| `TURNSTILE_SITE_KEY` `TURNSTILE_SECRET_KEY` | unset | Cloudflare Turnstile on making an account with a password at `APP_URL`, a proof of work at an organization's own domain; both or neither. See [Authentication](/configuration/auth#a-check-against-scripted-sign-ups) |
| `SIGNUP_CAPTCHA` | unset | `pow`: a built-in proof of work on making an account with a password, on every host Turnstile doesn't cover. See [Authentication](/configuration/auth#a-check-against-scripted-sign-ups) |
| `EMAIL_PROVIDER` | unset | `resend`, `postmark`, `sendgrid` or `console`. Set: every organization's email, and new accounts confirm their address with a code. Unset: no email, unless an organization sets its own |
| `EMAIL_FROM` `EMAIL_REPLY_TO` `EMAIL_API_KEY` | unset | Sender, reply address, provider key. `EMAIL_REPLY_TO` is also where Help's Send feedback writes; unset, the app offers none |
| `TERMS_URL` `PRIVACY_URL` | unset | Your terms and privacy policy. Set: wherever an account is made, it says that going on agrees to them, with links. `PRIVACY_URL` also shows as a "Privacy" link where visitors without an account land: portals (their door and requests for access too), share links and BrandHub |
| `BRAND_NAME` `BRAND_TAGLINE` `BRAND_ACCENT` | the product's | The server's brand, under every organization's own. See [White-labeling](/configuration/white-labeling) |
| `ANONYMOUS_SCOPE` | nothing | What a request with no key and no session may do: `read` makes a public library |
| `TRUSTED_PROXIES` | unset | The reverse proxies in front, whose `X-Forwarded-For` the server believes: addresses, ranges, or `private`. Unset, the header is ignored and every client shares one rate limit. See [Security](/configuration/security#client-addresses) |
| `RATE_LIMIT` | `1200` | `/api` requests per minute per client; `0` turns it off. See [Security](/configuration/security) |
| `LIMIT_STORAGE` `LIMIT_EDITORS` `LIMIT_WORKSPACES` `LIMIT_BRANDS` `LIMIT_DOMAINS` `LIMIT_EMAILS` `LIMIT_FEATURES` | unlimited | Every organization's limits. See [Limits](/configuration/limits) |
| `LIMIT_ORGANIZATIONS` | unlimited | Per person: how many organizations on the server's limits (no row of their own) someone may be admin of and still make another. See [Limits](/configuration/limits#for-every-person) |

## Settings

Some configuration is also a setting an organization can change for itself in
the app (Settings), such as its email. A value resolves property by property
from the narrowest place that says something: the workspace, then the
organization, then the environment, then the default. So a server configured
once serves every organization, and one of them can change what the server
leaves open to it. Email is an exception: once `EMAIL_*` is set, it is the
server's alone, and no organization overrides it.
`GET /api/v1/settings?context=organization` says where each value comes from.

Limits are the exception: an organization can read them, never change them.
