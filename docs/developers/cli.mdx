title: CLI

```bash
npx artbucket login app.artbucket.io --scope write
npx artbucket brand push brand --publish
```

The CLI is the `artbucket` package on npm, for Node 22 and later: `npx
artbucket` runs it anywhere, `npm install -g artbucket` keeps it. `login`
takes your server (`https://` is assumed without a scheme; give
`http://localhost:3000` in full), signs in through the browser with the
device flow, and keeps a key in `~/.config/artbucket/credentials.json`,
with that server as the default: later commands go there without
`ARTBUCKET_URL`, which still wins when set. It asks to suggest (`propose`),
what an agent gets by default: uploads wait for a person to approve them.
Pushing a brand edits it and `--publish` releases it, so that takes
`--scope write`; `--scope read` asks for less, and the consent screen never
offers more than you have. Disconnect it from Connections. Or set `ARTBUCKET_KEY`. From a
clone, `pnpm artbucket` runs the same CLI, and `pnpm link --global` puts it
on your path.

Without Node, the CLI is an image too: `ghcr.io/pwnera/artbucket/cli`, tagged like
the app's ([Docker](/guides/brand-as-code/cli#with-docker)).

```bash
docker run --rm -it -v artbucket:/config ghcr.io/pwnera/artbucket/cli login app.artbucket.io
docker run --rm -v artbucket:/config -v "$PWD":/work ghcr.io/pwnera/artbucket/cli brand push brand --publish
```

```bash
artbucket search sintel poster
artbucket search --status deleted
artbucket url {id} --width 1200 --format webp
artbucket check {id} --channel paid-social --territory DE
artbucket ingest ./hero.png https://example.com/logo.png --tag launch
artbucket ingest ./v2.png --version-of {id}
artbucket review
artbucket approve {id}
artbucket reject {id} --reason "off-brand colors"
artbucket rules --context instagram-story
artbucket keys create claude --scope propose
artbucket invite sam@agency.example --scope write --collection {id}
artbucket share {collection-id} --upload
artbucket audit
```

A brand's pages, rules and theme, from JSON files in the shapes the API takes:

```bash
artbucket templates
artbucket pages
artbucket page logo > logo.md
artbucket page save logo page.json
artbucket page edit logo ops.json
artbucket rules set rules.json
artbucket theme set theme.json
artbucket publish --note "New accent, and a page on logo use"
```

A brand as files for a Git repository ([brand as code](/guides/brand-as-code/cli)):

```bash
artbucket brand pull brand --brand acme --assets
artbucket brand diff brand
artbucket brand push brand --publish --note "Bluer primary"
```

In CI, with a write key (`artbucket keys create ci --scope write`) in
`ARTBUCKET_KEY`: `npx --yes artbucket brand push brand --brand acme --publish`.
[CLI and CI](/guides/brand-as-code/cli#from-ci) has every flag, and GitHub
Actions and GitLab CI recipes.

`--json` prints the raw API response. `artbucket --help` lists every command.
