# @artbucket/ui

Draw a brand's rules from an [Artbucket](https://github.com/pwnera/artbucket) release: the palette
(with contrast), the type specimen, logos, dos and don'ts, any rule's value. HTML strings for any
framework, web components, and React. MIT.

```js
import { palette, logoGrid } from "@artbucket/ui/html";   // strings
import { define } from "@artbucket/ui/elements";           // <ab-palette src="/brand.json">
import { Palette } from "@artbucket/ui/react";             // <Palette rules={...} />
```

Style: `@artbucket/ui/ui.css`. Docs: https://docs.artbucket.io/developers/kit
